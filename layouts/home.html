The model

One hash. Two stores. Every app.

tie splits what a file is from what it means. The bytes live in a content-addressed blob store; the meaning lives in triples. The content hash is the join, so tags, ratings and history follow the content — not the filename.

60 seconds

A library that behaves like a folder.

No service to run, no schema to design, no import you can't undo. Point tie at a directory, then browse it by meaning.

  • Import once. Tags attach to the content hash, so a rename or a re-import never loses them.
  • Mount it. Use Dolphin, Finder or Explorer — every path is a live tag query.
  • Nothing is locked in. Content hashes, TSV dumps and a single-file store that backs up with rsync.

How it's made

Small tools. Sharp edges filed off.

Local-first
The library is a file, the servers are optional, and nothing leaves your machine unless you mount it there.
Native, not browser-shaped
Go and Fyne. A single binary that starts in a frame, not a tab. Light and dark themes are designed, not inverted.
Honest engineering
Numbers are measured on the real database. Reverted experiments are written down. Limits are on the page.
Open and porous
BSD-3. Content addressed. TSV in and out. The Go and Python clients are first-class, not an afterthought.
Scriptable
fynerisor turns Fyne into a Risor canvas; anneal's Harness view is one. The UI can be extended without a rebuild.
Quiet by default
No telemetry, no accounts, no web fonts on this site. The only dependency is your own machine.
